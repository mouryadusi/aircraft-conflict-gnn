# Final Prediction-Level Evaluation

## Overview

This report presents the final prediction-level evaluation of the
Graph Convolutional Network (GCN) and Graph Attention Network (GAT)
models developed for aircraft conflict detection.

The evaluation uses the final prediction files generated by the
completed model pipelines.

## Important methodological note

The GCN and GAT prediction files contain different numbers of
evaluation samples and substantially different class distributions.

Therefore, the results cannot be interpreted as a paired,
same-edge comparison.

The comparison is instead reported as performance on each model's
respective final evaluation population.

This distinction is important because directly aligning the two
prediction files by row would not constitute a valid experimental
comparison.

# Model Comparison

| Model | Features | Precision | Recall | F1 | ROC-AUC |
|---|---|---:|---:|---:|---:|
| GCN | Trajectory | 0.6503 | 0.7343 | 0.6898 | 0.9862 |
| GAT | Trajectory + CPA | 0.0048 | 0.3333 | 0.0094 | 0.9420 |


## Interpretation

The GCN demonstrates substantially stronger practical conflict
classification performance in the final prediction-level evaluation.

The GCN achieves an F1-score of 0.6898 compared with 0.0094 for the GAT.

The GCN also achieves substantially higher precision while retaining
a relatively strong recall.

The GAT detects a proportion of the positive cases but produces a
large number of false-positive predictions relative to the number of
actual conflicts. This results in extremely low positive-class
precision and F1 performance.

The results demonstrate that increased architectural complexity and
the use of attention mechanisms do not necessarily produce better
operational classification performance.

## Class imbalance

The final GAT evaluation population contains a substantially lower
positive-class rate than the GCN evaluation population.

GCN positive rate:

0.022001

GAT positive rate:

0.000229

Consequently, accuracy and ROC-AUC should not be interpreted
in isolation. Positive-class precision, recall, F1-score, and the
confusion matrix provide more useful information about the practical
conflict-detection behaviour.

## Limitation

A definitive paired comparison between GCN and GAT would require both
models to generate predictions for exactly the same candidate-edge
population with a shared edge identifier.

The current prediction files do not contain such a common identifier,
and their evaluation populations differ substantially.

Accordingly, this report does not claim that the models were evaluated
on identical prediction instances.

## Final conclusion

Under their respective final evaluation populations, the GCN provides
substantially stronger practical conflict-detection performance than
the GAT.

The GCN's higher positive-class precision and F1-score indicate a more
useful balance between detecting genuine conflicts and limiting false
alarms.

The GAT results highlight the importance of evaluating imbalanced
conflict-detection systems using positive-class metrics rather than
relying solely on aggregate metrics such as accuracy or ROC-AUC.
